# Data Science Portfolio

Welcome! I’m Stephanie, and this portfolio brings together
coursework and personal projects as I continue developing
my skills in applied data science.

My interests include healthcare, life sciences, and finding
practical uses for data.

## Data Science Projects

### [MovieLens Movie Recommender](https://github.com/stephfn/movielens-movie-recommender)

An item-based recommendation system that uses MovieLens ratings and cosine similarity to identify movies with similar rating patterns.

### [Movie Review Sentiment Analysis](https://github.com/stephfn/movie-review-sentiment-analysis)

An analysis of movie reviews comparing TextBlob and VADER sentiment predictions against labeled reviews, with text preprocessing and exploratory analysis.

### [DICOM CT Protocol Classification](https://github.com/stephfn/dicom-ct-protocol-classification)

An ongoing project exploring CT protocol classification from DICOM metadata, comparing a rule-based baseline with an approach using a large language model.

### [Chemical Data Parsing Pipeline](https://github.com/stephfn/chemical-data-parsing-pipeline)

A project exploring the extraction and organization of chemical information from unstructured text, including safety data sheets, using text processing and similarity methods.

### [Honey Yield Predictive Modeling](https://github.com/stephfn/honey-yield-predictive-model)

A collaborative project exploring honey yield prediction through data preparation, feature engineering, and predictive modeling. Developed as part of a course team.

### [Housing Price Regression](https://github.com/stephfn/housing-price-regression)

A regression project examining housing price prediction through data preprocessing, principal component analysis, and model evaluation.

### [Pokémon Market Analytics](https://github.com/stephfn/pokemon-market-analytics)

An analysis of Pokémon card data using API collection, data cleaning, and SQL queries to explore pricing and card characteristics.

### [Loan Prediction Pipeline](https://github.com/stephfn/loan-prediction-pipeline)

A machine learning pipeline for loan prediction using data preprocessing, feature scaling, and hyperparameter tuning for a K-nearest neighbors classifier.

### [p53 Protein Structure Analysis](https://github.com/stephfn/protein-structure-folding-pipeline)

Analysis and visualization of an existing p53 protein structure, including residue distances, hydrophobicity, and structural features.

### [Classification and Feature Selection with Synthetic Data](https://github.com/stephfn/rna-seq-classification-pipeline)

A simulated gene-expression classification project comparing machine learning methods and examining how feature selection affects performance. Uses synthetic data rather than actual patient RNA-seq measurements.
