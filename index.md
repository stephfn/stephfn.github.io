## Projects

The following projects represent work completed through coursework, collaborative assignments, and independent exploration. They demonstrate different stages of the data science workflow, including data collection, preparation, analysis, modeling, evaluation, and interpretation.

### [DICOM CT Protocol Classification](https://github.com/stephfn/dicom-ct-protocol-classification)

**Focus:** Healthcare analytics, medical imaging metadata, classification, and large language models.

Developed and evaluated two approaches for classifying CT imaging protocols using DICOM metadata from the LIDC-IDRI dataset. The project compared a rule-based classification system with a zero-shot large language model.

The analysis included 573 CT series with usable descriptive metadata. The rule-based approach achieved 97.9% agreement with manually assigned reference labels, compared with 89.9% for the LLM.

The project also examined classification disagreements, ambiguous metadata, and limitations in the reference-labeling process. These findings illustrate the importance of data quality, transparent evaluation, and human oversight when applying automated classification to scientific and healthcare data.

### [Chemical Data Parsing Pipeline](https://github.com/stephfn/chemical-data-parsing-pipeline)

**Focus:** Chemical informatics, unstructured data, text processing, and data standardization.

Explores methods for extracting and organizing chemical information from unstructured text, including safety data sheets and other scientific documentation.

The project examines how text processing, chemical identifiers, and similarity-based methods can support the organization and comparison of chemical information.

This work reflects my interest in improving access to scientific data that may be distributed across documents, inconsistent naming conventions, and different representation formats.

### [MovieLens Movie Recommender](https://github.com/stephfn/movielens-movie-recommender)

**Focus:** Recommendation systems, similarity analysis, and collaborative filtering.

Developed an item-based movie recommendation system using MovieLens rating data and cosine similarity to identify movies with similar rating patterns.

The project explores how relationships between user ratings can be used to generate recommendations, along with the importance of data preparation and interpreting similarity measures.

It demonstrates an application of recommendation techniques to a dataset containing user preferences and item interactions.

### [Movie Review Sentiment Analysis](https://github.com/stephfn/movie-review-sentiment-analysis)

**Focus:** Natural language processing, sentiment classification, and model evaluation.

Analyzed movie reviews using text preprocessing, exploratory analysis, and sentiment classification techniques.

The project compared sentiment predictions generated by TextBlob and VADER against labeled reviews to examine how different approaches interpret positive and negative language.

The analysis highlights the challenges of translating natural language into structured sentiment labels and evaluating model performance against reference data.

### [Honey Yield Predictive Modeling](https://github.com/stephfn/honey-yield-predictive-model)

**Focus:** Predictive modeling, agricultural data, and collaborative data science.

A collaborative data science project investigating honey yield prediction using data preparation, exploratory analysis, feature engineering, and machine learning.

The project examined relationships between available variables and honey production, with an emphasis on developing and evaluating predictive approaches.

This work provided experience in collaborative analysis, coordinating project contributions, and communicating modeling results.

### [Housing Price Regression](https://github.com/stephfn/housing-price-regression)

**Focus:** Regression, dimensionality reduction, and predictive analytics.

Examined housing price prediction using data preprocessing, exploratory analysis, principal component analysis, and regression modeling.

The project investigated how different features and transformations affect predictive analysis and model evaluation.

It demonstrates the application of statistical and machine learning methods to a structured dataset involving economic and housing characteristics.

### [Pokémon Market Analytics](https://github.com/stephfn/pokemon-market-analytics)

**Focus:** API data collection, SQL, data cleaning, and market analysis.

Collected and analyzed Pokémon trading card data using an API, data preparation techniques, and SQL queries.

The project explored card characteristics and pricing information, demonstrating how external data sources can be collected, structured, and analyzed to investigate market-related questions.

It emphasizes data acquisition, organization, and querying as important parts of the analytical workflow.

### [Loan Prediction Pipeline](https://github.com/stephfn/loan-prediction-pipeline)

**Focus:** Classification, preprocessing pipelines, and hyperparameter tuning.

Developed a machine learning pipeline for loan prediction using data preprocessing, feature scaling, and a K-nearest neighbors classifier.

The project examined the importance of preparing data consistently and evaluating model configurations through hyperparameter tuning.

It demonstrates a structured approach to building and assessing a supervised classification workflow.

### [p53 Protein Structure Analysis](https://github.com/stephfn/protein-structure-folding-pipeline)

**Focus:** Structural biology, scientific computing, and molecular visualization.

Analyzed and visualized an existing p53 protein structure to explore structural characteristics such as residue distances, hydrophobicity, and spatial relationships.

The project applies computational analysis to biological structural data and demonstrates methods for investigating molecular features.

This is a structural analysis and visualization project rather than a system for predicting protein folding.

### [Classification and Feature Selection with Synthetic Data](https://github.com/stephfn/rna-seq-classification-pipeline)

**Focus:** Biological data simulation, classification, and feature selection.

Investigated machine learning classification and feature selection using a simulated gene-expression dataset.

The project compared modeling approaches and examined how selecting different features can influence classification performance.

The dataset is synthetic and does not represent actual patient RNA-seq measurements. The project is intended to demonstrate analytical methods relevant to high-dimensional biological data rather than make clinical or biological claims about real patients.
